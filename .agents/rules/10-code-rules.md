# 寫程式時才需要的細則

## 1. 圖示三軌（不可混用）

| 用途 | 用什麼 |
|---|---|
| 官方機制圖示 | 字型 `.fu-icon` |
| 敘事槽位（物種／範本／職業／定位／資源／裝備類別／屬性／反派階級／區塊標題／徽章／空狀態） | `react-icons/gi` |
| 功能性控件（返回／關閉／搜尋／新增／折疊／排序／篩選／複製／刪除） | `lucide-react` 或純排版字符 |

禁彩色 emoji。新增例外詞要改**判定規則**，不要只往黑名單加詞。

## 2. 九相屬性內聯

一律走 `renderTextWithAffinities`（判定在 `src/components/ui/affinityText.js`）。
原則：**寧漏不誤**。改判定規則時要同步補 `test:affinity` 的誤標表。

## 3. 護欄（測試）寫法

1. 新增護欄後必須做**刻意破壞驗證**：改壞 → 確認 FAIL → 還原。
2. 破壞腳本必須斷言「替換真的發生了」：`if (s === orig) process.exit(1)`。
   已知兩種假綠燈：`String.replace()` 只換第一個（而第一個在註解裡）、
   **檔案是 CRLF 而替換字串用 `\n`**（靜默不匹配，測試全綠，看起來像護欄沒用）。
   `src/` 有 CRLF 檔（`classResources.js`、`CharacterEditor.jsx`、`CreationRulesPanel.jsx`），
   `tests/` 是 LF。跨行替換前先 `s.includes('\r\n')` 確認。
3. `html.includes('x')` 斷言前先問「別處是否也有這字串」。
4. 「至少有一個」型斷言太弱 → 改寫成「逐一都必須成立」。
5. `onClick` 裡的邏輯 SSR 測不到 → 抽成純函式再測。
   抽出的 `.jsx` 一律要 `import React`（Vite 用 automatic runtime，esbuild 用 classic）。
6. 面板的「展開態」SSR 測不到 → 給 `defaultOpen` 起始狀態 prop，測試傳 `true`。
7. 紅燈先分類：**是我弄壞的，還是那條斷言一直在記錄舊行為？**
   改斷言時要留住它順帶守的東西，並在旁邊寫下為什麼改。

## 4. 五個高頻陷阱

1. **改共享資料前先問「這是誰的物件」。** `rulesData` 的物件被多處共用，
   一律 `{ ...obj }` 複製後再改。
2. **同一份資料被兩處以不同寫法比對，就一定有第三處會比錯。**
   大小寫不一致是最便宜也最貴的 bug（`'MP' === 'mp'` 只是回 false，程式照常跑完）。
   遇到列舉值先做一個正規化入口，不要逐一改字面值。
3. **死掉的顯示分支比錯的顯示更難發現。** `{x ? ... : null}` 在 `x` 永遠是空字串時
   不是「印錯」，是**從來沒印過**。護欄要問「這個欄位有沒有可能永遠是空的」。
4. **「修好」之前先數「總共幾處」。** 一句話寫在 N 個地方是常態
   （「N~M 個職業」共 5 處，修了看得見的 2 處，編輯器裡還印著「3~3」）。
   修完用 grep 找**所有**同義寫法，並加一條**掃原始碼**的護欄。
5. **「有沒有」型的量測先確認狀態。** 某些文字只在特定狀態才存在
   （開職業選擇器／選過二選一／定稿後）。狀態組合太多就換判定單位：
   逐畫面數 → 逐項目查全站。

## 5. 要開瀏覽器做實機驗證時

不要用 `npm run dev &`（背景伺服器會被 shell 回收）。
用 `node scratch/run-live.mjs <腳本>`——它同一個行程內起伺服器、等 HTTP 200、
跑腳本、關伺服器。（`scratch/` 不進版控，腳本重建即可。）

一次 `eval` 只能點一顆按鈕：React 在單次 eval 內不重繪，
同步 `for` 迴圈會反覆點到**同一顆**。改一次點一顆 ＋ `await wait()`。

按鈕文字用「含子字串」比對，不要用「精確等於」。

## 6. UI 設計方向（v5）

「全程淺色 · 冷暖分層」。兩區：冷區＝操作型、暖區＝閱讀型。
判準一句話：**「要『做』還是要『讀』？」**

紅線：禁黑金、禁深底白字高密度、禁 emoji、禁漸層、禁裝飾性光暈、
禁用 box-shadow 造浮起感。

**常駐面板一律預設收合 ＋ 一行摘要。**
理由：面板在編輯器八個分頁都常駐，展開就吃掉每頁第一屏一半。
摘要必須回答「跟官方標準不同哪幾條」，且**只算真正不同的**。
