# P14：按了指令就換掉右翼那扇窗（2026-11-02）

> 使用者原話（一句話裡有四件事，照他的順序編號）：
>
> 「是有游戏的感觉了。但**左边六个大按钮**，然后点了之后**还要特地滑下去才看得到视窗**，
> 操作很反人类诶。我建议可以**点了按纽就会把立绘右边的视窗直接整个替换掉**。
> 然后左边的按纽**多加一个个人资料**之类的来显示最基本的默认信息。你觉得如何？
> 然后**不要这么宽松**的话，我建议把**左栏的长压缩**，**给右栏更多显示信息的空间**，
> 然后把**四维用横排写出来**。这样状态效果和四维所占据的宽就不必这么多，
> 后面切换按钮显示信息也更容易读。」

P13 把內容印在 hub **下方**，按鈕在上面、內容在一屏之外——這是 P12 那條
「分頁列釘住」想解而沒解乾淨的問題。P14 換方向：**內容不要離開視野**。

## 1. 四件事的落地

| # | 使用者要的 | 怎麼做 |
|---|---|---|
| ① | 按了就換掉右翼那扇窗 | 分頁內容從 hub 下方**搬進右翼**，`hud-panel-window` 一扇窗、內容跟著 `activeTab` 換。舊的 sticky 分頁列整條拆掉 |
| ② | 多一顆「個人資料」 | `profile` 是**第一頁也是預設頁**：狀態（HP／MP／IP 步進器）、四維、狀態異常、成長、資產 |
| ③ | 左欄壓縮、右欄更多空間 | 版面 3 / 4 / 5 → **2 / 4 / 6**；列高從「`flex-1` 撐滿」改成固定 44px；指令窗 `self-start`（貼齊頂端，不再被拉到和右翼一樣高） |
| ④ | 四維橫排 | `grid-cols-2` → `grid-cols-2 sm:grid-cols-4`，一列四格 |

## 2. 一個必要的例外：常駐狀態條

使用者說「**整個**替換掉」。但 HP／MP／IP 不能跟著被換走——跑團時那是每 30 秒
要看一次的東西，切到「武器與戰鬥」就看不到自己剩多少血，那張卡就不能用了。

所以把它壓成一條細條，掛在**立繪身上**（這三個數字本來就是「這個角色現在怎麼樣」），
右翼那扇窗才真的可以整個換掉。這條是**純顯示**：裡面沒有步進器、沒有輸入框
（`DA-3` 有反向斷言守著），點它就跳到「個人資料」頁。

## 6. 六個坑

1. **`testId` 是 prop，不是 `data-testid`**。`hud` 這個變數讀的是**原始碼**，
   裡面寫的是 `testId="hud-panel-window"`；拿 `data-testid=` 去比對原始碼永遠 0 命中。
   （同一個坑 P13 撞過一次，這是第二次。）
2. **`clickText` 找不到時不拋例外**，只回 `{ ok:false, reason:'not found' }`。
   於是「點不到」與「點了沒事」長得一模一樣，後面每一條都紅在「量不到 HUD」。
   現在每一步都用 `waitForText` 等到文字出現，並逐段驗「我真的到了那一頁」。
3. **角色卡是 lazy-load**：點完「角色卡助手」會停在「正在繪製圖紙……」。
   固定 `wait(900)` 有時不夠——`verify-p12` 就是這樣紅的，而**功能其實是好的**。
4. **設計系統的 `font-mono` 有全域預算（481）**。狀態條的標籤與數字各加一個就爆了（482）。
   正解不是調上限，是那兩格本來就只需要 `tabular-nums`。
5. **`aspect-ratio: 3/4` 是上限也是下限**：`flex-1` 有剩餘高度時會超過它，
   沒有剩餘高度時就退回 3:4。左欄變矮 → 整列變矮 → 圖跟著塌，這是**連鎖**不是獨立問題。
6. **前提寫太嚴會紅錯地方**（三個例子）：
   右欄寫「≥ 620px」（實際 578＝6/12 × 1172，是我算錯）、
   列高寫「＝ 44px」（`min-h` 是下限，實測 49）、
   sticky 寫「捲到 420」（那一頁最多只能捲 150）。
