# 05 · 職業技能（28 筆，八群）

> 本檔是計劃書的分冊（給 Antigravity 分冊閱讀）；入口與施工順序看 `docs/plan/README.md`。
> 逐筆原文引用、「面板做一半」的逐條缺口看 `appendix-class-needs.md`（458 行，含檔案:行號）。

## 0. 先讀這三句

1. **這一類的缺口不是「按不到」**：`effectFlows` 已經會渲染控件、會扣成本（`flow-control` 70 筆）。
   缺的是 `{n, on, choice}` **裝不下的三種東西**：清單型（具名實體）、物件型（效果掛在藥水／美食上）、
   多步驟／跨面板型（播種→離園、表演→共享、宣告→擲骰→換值、命刻→補格）。
2. **先修「有面板但只做一半」的 24 筆**（附錄有逐條清單），再談新元件——那 24 筆是既有功能的漏洞。
3. **【植生術】是 W0-9 的標準案例**：通用按鈕扣 20 MP 但不加種子、花園盤加種子但不扣 MP。
   凡是 `apply.via` 從 `flow-control` 改成 `existing`，**必須同時確保通用按鈕消失**。

通用按鈕只寫 `flowState`，什麼都沒發生。修法同 W0-9：**要么接上真效果，要么移除按鈕**。

## 2. 逐群施工步驟

### C5 花園三補（**第一優先**，因為它同時是 W0-9 的驗收）
1. `FloristGardenTracker` 的「種下」改成一次寫入：`currentMp -= 20` ＋ 種子進花園（同一筆 `onChange`）。
2. 【嫁接】：換種時保留原命刻（`growthClock` 不歸零）。
3. 【生命之樹】：離園治療（一個動作把植物收回，回 HP）。
4. 驗收（`test:florist` 追加 ≥6 條）：扣 20 MP、MP 不足不種、嫁接保命刻、離園治療、通用按鈕已消失、履歷一筆。

### C3 貿易池收斂（W0-8 的驗收）
1. `effectFlows` 的 4 筆改 `backedBy: 'tradePoints'`（不畫 counter）。
2. 面板加一顆「花 2 點」按鈕（原文：貿易之風的點數可換取好處）。
3. 驗收：跑團卡只出現**一個**貿易點數；花點數寫進 `classResources` 並留履歷。

### C1 物件型（5 筆，一次改資料模型吃五筆）
1. `utils/inventory.js` 的 item 加 `effectModel: { heal?, buff?, onUse? }`（不要每件物品寫一段程式）。
2. `BackpackItemModal` 加「使用時的效果」欄位（存成資料，不執行）。
3. 5 筆技能改成「產生／修改物品的 `effectModel`」，不再各自寫流程。
4. 驗收：`test:inventory` 追加 ≥5 條（模型可存、讀回一致、舊物品沒有模型時不炸）。

### C6 徽記實體（2 筆）
1. 新 `SymbolistMarks.jsx`：每枚徽記一筆 `{ id, symbolId, carrier, note, destroyed }`。
2. 【徽記學】生成／摧毀；【咒語徽記】依賴同一份清單（**不要**第二份）。
3. 驗收：19 種徽記都能建立；摧毀後不再出現在清單；`carrier` 可選自己或隊友名冊。

### C2 旅行骰（4 筆）
1. 先寫純函式 `utils/travelRoll.js`：骰階（d6→d12）、加值、`SL` 判定。
2. 面板顯示「本場景的旅行骰」與一顆「擲」；結果寫履歷。
3. 驗收：骰階換算、`SL+1` 門檻、重擲（地圖測繪）各一條。

### C4 暫存效果表（4 筆）
1. `character.pendingBuffs[]` = `{ id, source, target, effect, expiresIn }`。
2. 掛在「情感羈絆」分頁下方（跨場景會用到的暫存效果都在這一區）。
3. 到期時機：場景結束／休息（由 W0-7 的重置列一起處理）。
4. 驗收：新增／到期／手動移除各一條；**不寫別人的卡**（裁定 D5）。

### C7 / C8（單筆）
- 【孤注一擲】：擲骰器加 `mode:'doubleEven'`（偶數翻倍、其餘視為 1），判定抽成純函式。
- 【幸運七】：擲骰器加「改一顆骰的值」，值寫 `flowState`（每場景一次）。
- 【不屈意志】：把「空轉按鈕」接上「本場景不死一次」的旗標（`flowState.on`）。
- 【嵌合學派儀式】：`choice` 存 `INS+WLP／MIG+WLP`，`spellGrants` 讀它（不要寫死預設）。
- 【忠實夥伴】：HP 0 逃歸隊、休息共享兩步補在 `WayfarerCompanionModal`。
- 【靈光一閃】：`list` 記錄「哪個目標已用過」。

## 3. 刻意不做

- 不改共用驗證（`customWeapons`／`buildLoadoutIssues`）去檢查價值上限。
- 不把「操作別人的卡」做出來（裁定 D5）。
- 命刻改由角色卡持有是 `07-fateclocks-to-character.md` 的工作，**不要**在 C4 裡順手改。
