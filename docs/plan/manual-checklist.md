# 角色卡實機走查清單（W0–W6 全部修正）

> 這一份是給**人**看的：每一步都寫「你點哪裡 → 應該看到什麼 → 沒看到代表哪個模組壞了」。
> 圖示三軌、字級那些規範不在這裡——這份只驗「有沒有效」。
>
> 建議流程：**先用 G1 建一個測試角色**（下面步驟 0），再照表走。
> 每一步都有一個「怎麼確定它是真的」的做法：多按一下、重新整理、或切到別頁再回來。
>
> 標記說明：`✔` 現在應該就要有；`▲` 有入口但要手動操作才看得到；`✗` **目前還按不到**（見 §9）。

---

## 0. 準備（3 分鐘）

1. 角色列表 → 建立角色 → 名字隨便（例：`走查用`）。
2. 選職業：**植物學家**（技能選【植生術】）、**徽記師**（【徽記學】）、**美食家**（【烹飪】）、
   **商人**（【貿易之風】、【我聽說過】）、**吟唱者**（【能言善辯】）、**旅人**（【有備無患】）。
3. 英雄技能挑：**【富家子弟】以外的先不用**；另外挑【靈氣掌握】、【穩固突變】、【本店特色】、
   【大吃一頓】、【偉大召喚】、【解剖學家】、【樸實之力】、【升級】。
4. 金手指挑：**【地獄差生】**（這次回報的那一個）。
5. 資金：記錄一下現在多少 z（走查【升級】時要對數字）。

> 為什麼要這麼齊：這份清單總共會碰到 8 個面板、20 顆按鈕、6 條資源刻度。
> 分散在幾張卡上會很難看出「數字有沒有真的動」。

## 1. 三顆重置鈕（W0-7）

**位置**：職業技能分頁 → 最上方工具列（「營地休整」旁邊）。

| 步驟 | 應該看到 |
|---|---|
| 1-1 看工具列右側 | 三顆小按鈕：**重置場景**、**重置休息**、**重置章節** |
| 1-2 先在某個技能按一次「用」（例：職業技能【不屈意志】的按鈕） | 該技能上的數字／狀態變了 |
| 1-3 按 **重置場景** | 跳出 toast「已重置 N 條【場景結束】效果」；剛才那個數字歸零 |
| 1-4 再按一次 **重置場景**（已無可重置） | toast「目前沒有【場景結束】可重置的條目」——**不該**卡住或當掉 |

**沒看到**：`CharacterPlayHUD` 的 `resetFlowScope` 接線。
**怎麼確定它是真的**：按「重置休息」不應該清掉「場景」那批（兩者 scope 不同）。

## 2. 資源刻度與「擲骰回充」（W0-3）

**位置**：個人資料分頁下方「職業資源」；以及**金手指卡片內**（差生點）。

| 步驟 | 應該看到 |
|---|---|
| 2-1 個人資料 → 往下找「職業資源」 | 依你的職業出現刻度（植物學家會看到對應池、商人會看到**貿易點數**） |
| 2-2 找有「擲 1d6」字樣的那一條（疲勞值／不穩定值那類） | 按鈕寫「每章節恢復 1d6」或「擲 1d6」 |
| 2-3 按它 | 數字往下掉 1–6，toast 寫出實際骰值 |
| 2-4 連按到 0 為止 | 不會變負數；到 0 就停 |

**沒看到**：`ClassResourceStrip` ＋ `applyRollDelta`。

## 3. 【富家子弟】完整面板（W1）

**位置**：職業技能分頁 → 往下「金手指特質」區塊。

| 步驟 | 應該看到 |
|---|---|
| 3-1 選了金手指【富家子弟】 | 卡片內出現「**保鑣**」面板，寫「至少 2 位」 |
| 3-2 還沒填名字時 | 三個增益按鈕是**灰的**，下面寫「尚未填齊資料」 |
| 3-3 按「＋ 新增」兩次、各填名字與外表 | 兩筆保鑣出現；增益按鈕變**可按** |
| 3-4 按其中一個增益 | 疲勞值刻度上升（+1d6）、toast 寫出骰值與「疲勞值 x → y」 |
| 3-5 把疲勞值加到 10 | 三顆增益全部變灰，並寫「已達上限」 |
| 3-6 按 **重置休息** | 疲勞值往下（−1d6），但**保鑣名字還在** |
| 3-7 重新整理頁面 | 名字、疲勞值都還在（存得住） |

**沒看到**：`flowDataSpecs`＋`FlowDataPanel`（W1 的核心）。
**怎麼確定它是真的**：3-6 是關鍵——「重置不清名字」是刻意的設計（D2）。

## 4. 金手指的多控件與「每場景一次」（W2）

**位置**：職業技能分頁 → 金手指特質區塊。

| 步驟 | 選哪個金手指 | 應該看到 |
|---|---|---|
| 4-1 | 【被束縛的心】 | 一個「違反戒律（每場景一次）」按鈕 ＋ 一個「累計違反次數」計數器 ＋ 一個文字欄位 |
| 4-2 | 同上，按一次按鈕 | 按鈕變灰、寫「本場景使用次數已達上限（1／1）」 |
| 4-3 | 同上，按 **重置場景** | 按鈕恢復可按（次數真的回充） |
| 4-4 | 【大夢一場】 | 計數器 ＋ 文字欄位（原世界身份與執念）都在 |
| 4-5 | 【天才發明家】 | **兩顆**按鈕（IP 成本歸 0／花 1 物語點自備零件） |

**沒看到**：`controls[]`（W2 把 16 筆金手指改成多控件）。
**怎麼確定它是真的**：4-2 → 4-3 這對最能證明「重置有接上」，不是只有寫字。

## 5. 【升級】：特性挑選與扣款（W3）

**位置**：職業技能分頁 → 英雄技能區塊 →【升級】卡片。

| 步驟 | 應該看到 |
|---|---|
| 5-1 卡片內 | 面板標題「升級：每次休息一次，為裝備添加／替換特性」＋「＋ 新增」 |
| 5-2 按「＋ 新增」 | 出現五個欄位：裝備名稱、**類別（下拉）**、**特性（下拉）**、被替換的舊特性、支付金額 |
| 5-3 先不選類別就看「特性」下拉 | 是灰的，並寫「先在上面選『類別』」 |
| 5-4 類別選「武器」→ 開特性下拉 | 列出 **11 個** ≤1000z 的特性（魔能／獵人／穿刺…多重 1000z）；**不該**有「免疫」（1500z） |
| 5-5 選「穿刺」 | 支付金額**自動變成 400**（若你有【高瞻遠矚】SL2，會是 200） |
| 5-6 按「套用（扣款並寫履歷）」 | 資金減少對應金額；該筆變成「✓ 已套用（支付 200z）」 |
| 5-7 再按一次同一筆 | 按鈕已消失（不能重複扣款） |
| 5-8 去「金錢與物語點」分頁 | 履歷多一筆「【升級】為【旅行長劍】附加特性【穿刺】…」 |

**沒看到**：`FlowDataPanel` 的 `options/source/numeric` ＋ `applyUpgradeDraft`。
**怎麼確定它是真的**：5-6 前後的資金數字一定要變；只寫履歷沒扣錢就是壞的。

## 9. 目前**還按不到**的 8 筆（先不要浪費時間找）

這 8 筆的邏輯寫好了、`effectFlows` 也標成「交給既有面板」，但**沒有任何畫面元件呼叫那個模組**，
所以你在角色卡上找不到入口：

| 模組 | 影響的職業技能 |
|---|---|
| `utils/travelRoll.js`（旅行骰） | 旅人【有備無患】【寶藏獵人】【通曉道路】、美食家【準備食材】 |
| `utils/pendingBuffs.js`（暫存增益） | 靈師【支援魔法】、吟唱者【我相信你】【能言善辯】、機師【壓縮技術】 |

**這是真的缺口，不是你看漏了。** 補法是各做一個小面板（旅行骰：顯示骰階＋一顆「擲」；
暫存增益：一列清單＋到期按鈕），我可以排在下一輪。

## 10. 找不到東西時，先看這三個地方

1. **分頁不對**：金手指／英雄技能都在「**職業技能**」分頁（不是「個人資料」）。
2. **沒有那個技能就不會有那個面板**：例如【植生術】的花園盤要角色真的學了才出現。
3. **數字沒動但 toast 有字**：那是「只寫履歷沒改資料」——屬於壞掉，請記下來告訴我。

> 走查完請把「第幾步、看到什麼、跟預期差在哪」貼回來即可，不用整理。
