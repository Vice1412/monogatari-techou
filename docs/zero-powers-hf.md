## 1. 定譯全文

### 1.1 概觀（p.124）

底力技是為「玩家角色在走投無路時釋放出難以置信的力量」這種故事而設計的可選規則。
它特別適合高度奇幻戰役，但任何遊戲都能使用。

這條規則會讓故事的主角們強得過分。與任何可選規則一樣，請先與整團討論過再決定是否使用。

平均而言，使用底力技的團隊預期能輕鬆擊敗大多數敵人——除了那些需要特定策略或複雜戰術才能應付的對手。

### 1.2 創造底力技（p.124）

每個能使用這條規則的角色都必須創造屬於自己的底力技：從後述清單中**選擇一個觸發條件與一個效果**。

同一團隊中，**不得有兩名以上玩家角色擁有相同的底力觸發，也不得有兩名以上玩家角色擁有相同的底力效果**。

### 1.3 使用底力技（p.124）

若你的角色擁有底力技，他會獲得一個**底力命刻**。這個命刻有 **6 個刻度**，可在衝突場景中依下列方式充能：

- 每當你花費 1 點物語點來引用特質或羈絆時，填充 1 個刻度（每花費 1 點分別計算）。
- 每當你失去 HP 時，填充 1 個刻度——除非該損失是你自己造成的（例如靈師職業的【活力魔法】技能）。
- 當你所選的底力觸發條件發動時，填充對應數量的刻度。

在衝突場景中輪到你的回合時，若你的底力命刻已滿，你可以執行**技能動作**來施展你的底力效果。**每回合只能施展一次。**

- 施展底力效果會清空底力命刻的所有刻度。
- 每個場景結束時，底力命刻的所有刻度自動清空。
- 除上述方式、或透過【零之機運】效果外，底力命刻的刻度不得以任何方式填充或清空（見 §1.5）。

### 1.4 底力觸發（Zero Triggers，p.125）

| 觸發 | 填充數量 | 發動條件 |
|---|---|---|
| **憐憫** Compassion | 每次 1 個刻度 | 當你恢復一個或多個盟友的 HP **和／或** MP 時發動（只限「本身就會恢復 HP 或 MP」的效果；因另一個效果而提高恢復量的不算）。 |
| **挑戰** Defiance | 每次 1 個刻度 | 在衝突中，你的回合開始時，若場景中存在一個或多個**反派和／或冠位階級**的敵人，則發動。 |
| **愛** Love | 每次 1 個刻度 | **特殊規則**：選擇這個觸發時，將它綁定到另一個你愛上的玩家角色（這份感情不必是雙向的，但請確認整團都能接受這種互動）。<br>當你所愛的角色失去 HP（除非該 HP 損失是自己造成的）**和／或投降**時，只要你看得見他，就發動。<br>若你所愛的角色**犧牲**自己、且你目睹了那次犧牲，**填滿**你的底力命刻；並在該場景結束時，為你的底力技改選另一個觸發條件。 |
| **復仇** Revenge | 每次 **3** 個刻度 | 當你在一個場景中**第一次進入危機狀態**時發動。 |
| **連續** Sequence | 每次 **2** 個刻度 | 當一個你能看見的盟友施展其底力效果時發動。 |
| **戰略** Strategy | 每次 1 個刻度 | 在衝突中，你的回合結束時，若場景中存在的一個或多個敵人**合計**承受兩種或以上的不同狀態效果（例如一名同時陷入眩暈與虛弱的敵人，或一名緩慢的敵人加上另一名憤怒的敵人），則發動。 |
| **協同** Synergy | **變動**（見下） | 當你對一個或多個生物造成傷害時發動：每有一個**對該次傷害類型處於弱點**的生物，填充 1 個刻度。 |

### 1.5 底力效果（Zero Effects，p.126–127）

> 效果名稱採「零之X」體系，理由見 §4.1；CHM 舊譯名並列為檢索別名。

#### 零之疾襲 Zero Blitz（p.126）

你以**每一把已裝備的武器**各進行一次自由攻擊。
若你只裝備一把武器，該攻擊額外造成 **20** 點傷害；若你裝備兩把以上武器，則每次攻擊的命中檢定獲得 **+5** 加值。

#### 零之機運 Zero Chance（p.126）

選擇**奇數**或**偶數**，然後骰 **3d6**，看有幾顆骰子符合你的預測。
接著，**套用對應的效果，或緊接在其上一行的效果——由你選擇**。

- **零顆**：填充你的底力命刻 **3** 個刻度，並填充每個你能看見的其他玩家角色的底力命刻 **1** 個刻度。然後，執行一個額外動作。
- **一顆**：你以一把已裝備的武器進行一次自由攻擊。該攻擊額外造成等同 **3d6 總和**的傷害。
- **兩顆**：你對一個你能看見的生物造成等同 **（30 ＋ 你等級的一半 ＋ 3d6 總和）** 的傷害。此傷害沒有類型（無視親和度）。
- **三顆**：你與每個你能看見的盟友從所有狀態效果中恢復，並恢復等同 **（你的危機值 ＋ 3d6 總和）** 的 HP 與 MP。

最後，若三顆骰子點數相同，你可以在本回合中執行一個額外動作（**這與「零顆」給予的動作是分開的**）。

> **歧義（原文如此）**：「上一行的效果」按版面順序＝**較弱的一檔**。清單由上而下是 零顆→一顆→兩顆→三顆。
> 因此：三顆可改選兩顆、兩顆可改選一顆、一顆可改選零顆；零顆無上一行。
> 實裝時應做成「對應檔／上一行檔」二選一，**不要**自行改成「更好的一檔」。

#### 零之成本 Zero Cost（p.126）

直到場景結束前，你所有的**庫存點成本視為減半**。你也可以立即免費執行**庫存動作**。

#### 零之元素 Zero Elements（p.126）

**特殊規則**：選擇這個效果時，從風、電、暗、土、火、冰、光、毒中**選擇兩種傷害類型**。

你獲得以下好處：你造成的**所有傷害**都會變成你在這兩種之間**所選的一種**（於施展時選定）；**該傷害類型無法被其他效果改變**；且它**無視吸收、免疫與抗性**。
此外，你額外造成 **5** 點傷害（不論是攻擊、咒語、物品、阿爾卡納或任何其他方式）。

這些好處持續到場景結束、直到你再次施展此底力，或直到你主動結束它（你隨時可以這麼做）。

你也能在本回合中執行一個額外動作。

#### 零之極限 Zero Limits（p.127）

直到場景結束前，你的**所有屬性視為提升一階骰尺寸**（最高 d12）。你也能在本回合中執行一個額外動作。

#### 零之魔法 Zero Magic（p.127）

你免費執行**咒語動作**，施展一個你已學會的咒語；該咒語的**總 MP 消耗視為 0**（包含因技能與效果而增加的任何消耗）。
該咒語額外造成 **10** 點傷害；若它是攻擊性咒語（O），你的**魔法檢定獲得 +5** 加值。

#### 零之目標 Zero Objective（p.127）

**選擇一項**：填充與當前場景相關的**一個**命刻的 **3** 個刻度；或清空與當前場景相關的**一個**命刻的 **3** 個刻度。

> 兩句各寫「a Clock」，因此填充與清空可以指向**不同**命刻。

#### 零之救濟 Zero Remedy（p.127）

你與任意數量你能看見的盟友從所有狀態效果中恢復，並恢復等同 **（40 ＋ 你等級的一半）** 的 HP。

#### 零之天災 Zero Scourge（p.127）

**特殊規則**：選擇這個效果時，從風、電、暗、土、火、冰、光、毒中**選擇一種傷害類型**；然後從眩暈、動搖、緩慢、虛弱中**選擇兩種狀態效果**。

選擇任意數量你能看見的生物：你對每個目標造成等同 **（30 ＋ 你等級的一半）** 的所選類型傷害，且他們承受所選的狀態效果。

> **歧義（原文如此）**：前句要求「選兩種」，後句寫 `the chosen status effect`（單數）。
> 依「先選兩種」的前文與 CHM 譯法，實裝取**兩種都施加**。若日後有 errata 再修。

#### 零之盾 Zero Shield（p.127）

直到你的下一個回合開始前，你與**場景中在場的每一位盟友**受到的所有傷害**減半**（在計算親和度之前）。

#### 零之三角 Zero Triangle（p.127）

你與至多兩名**你能看見**的盟友，以**你裝備的一把武器**各進行一次自由攻擊（若他們是 NPC，則改為進行一次基本攻擊）。這些攻擊的命中檢定獲得 **+5** 加值。

> 注意：是「**你**裝備的武器」——盟友借用你的武器，不是各自的武器。

### 1.7 變體規則（p.130–131）——CHM 未收錄

#### 1.7.1 覺醒之力（Awakened Power，p.130）

適合「英雄在瀕臨毀滅之際、或因某件事改變了看待世界的方式，而顯現出意想不到的新力量」的史詩故事。

選擇這個選項時，**創造角色時只選效果、不選觸發**。你在以下情況「覺醒」之前無法使用該力量：

- 當你的角色在衝突中 HP 降至 0 時，你可以選擇覺醒，而**不是**投降或犧牲。
- 當你的角色面對一個可怕的真相、一件帶來極大喜悅或痛苦的事件或記憶，或取得對故事至關重要的力量來源（例如一件神器）時，你可以選擇覺醒。

角色覺醒時，立即恢復等同其**危機值**的 HP，並取得其底力技。他還必須選擇一個**與促成這次潛能釋放的事件相符**的底力觸發。若覺醒發生在衝突中，底力命刻**立即填滿**。

一名玩家角色在一場戰役中只能使用這條規則**一次**。由玩家決定覺醒的時機——只要確認那個時刻夠合適。

#### 1.7.2 合體之力（Combined Powers，p.131）

這個選項把底力技連到團隊成員之間的羈絆上，而不是綁在單一角色身上。

選擇這個選項時，套用以下規則：

- 每名玩家角色依正常規則取得一個底力觸發，以及一個 **4 格**（而非 6 格）的底力命刻。
- 每名玩家角色**對每一個其他玩家角色**各取得一個底力效果——由大家共同決定。**每一對玩家角色共用一個底力效果。**
- 只有當**兩人的命刻都滿**時才能施展該效果。只需其中一人執行技能動作，該動作會清空**兩個**命刻。

範例：你的團隊有四名玩家角色，因此有四個各自的底力觸發、共六個底力效果。槍手與武士共用【零之天災】，他們把它暱稱為「彈斬」。當兩人的底力命刻都滿了，任一人便可在自己的回合執行技能動作施展「彈斬」。

底力效果只結算**一次**，如同角色施展了一次標準底力技。

這個複雜選項只建議在**四名以下**玩家角色時使用。每次團隊成員變動時，記得重新整理可能的組合——這也是為什麼同一團隊裡出現一個以上相同底力效果是可以的。不過觸發條件若有可能，仍應全部不同。

若你把這個選項與前述的覺醒之力合併使用，只要把順序反過來：**創造角色時選觸發**，並在**某位玩家覺醒時**才決定每一組組合的效果。此外，每名玩家角色對戰役中每一個能與之組成合體之力的玩家角色，各擁有**一次**覺醒機會。

| A1 | 零之機運 | 只寫「根據對比的結果來決定這次底力的效果」 | `apply the corresponding effect **or the effect immediately above it, your choice**` | **整條選擇權消失**。原書允許降一檔換取另一種收益（例如三顆改選兩顆）。這是玩家每場都會用到的操作，漏掉等於改規則。 |
| A2 | 零之三角 | 「使用**你們**裝備的一件武器」 | `a weapon **you** have equipped` | 變成盟友各用自己的武器，強度差一個量級（原書是盟友借用**你**的武器）。 |
| A3 | 零之元素 | 「**例外**，你會造成 5 點額外傷害」 | `**Additionally**, you deal 5 extra damage` | 「例外」把「此外」讀成「除了上述之外的特例」，語意反向。 |
| A4 | 零之元素 | 「其傷害類型不能改變」 | `all damage you deal becomes of a type **of your choice** among the two you selected …, its type cannot change` | CHM 未區分「**施展時**選定」與「**創造時**就固定」。原書的意思是：施展時從兩種中選一種，持續期間鎖定、且不被其他效果改寫；下一輪再施展可以重選。 |
| A5 | 零之盾 | 標題作「屏障**Zero Remedy**」 | `Zero Shield` | 與【零之救濟】同名，實裝時會撞 key。 |
| A6 | 觸發·愛 | 「如果你目睹了你愛的角色**死亡**」 | `If the character you love **Sacrifices themselves** and you witness their Sacrifice` | 原文是核心規則的**犧牲**動作（以自身死亡換取他人存活），不是任何死亡。這決定「填滿命刻＋改選觸發」是否觸發。 |
| A7 | 觸發·憐憫 | 「恢復一個或多個盟友的 HP **或** MP」 | `Hit Points **and/or** Mind Points` | 少掉「同時恢復 HP 與 MP 也只算一次」的讀法；「和／或」在規則文本裡是必要精度。 |
| A8 | 零之目標 | 「填充**或**清除……的 3 個刻度」 | `**Choose one option**: fill 3 sections of a Clock …; or erase 3 sections of a Clock …` | 少了「二選一」的明示，也漏掉兩句各自寫 `a Clock`（可指向不同命刻）。 |

| # | 位置 | 歧義 | 本文件採用的讀法 |

## 4. 裝進角色卡助手：資料形狀建議

### 4.1 命名：為什麼建議改成「零之X」

CHM 的裸詞譯名（成本／元素／極限／咒語／目標／救濟／天災／三角）在**規則書排版**裡靠粗體就能區分，
但放進 UI 會與高頻通用詞直接撞車——「目標」「元素」「咒語」在角色卡里天天出現，
玩家看到選單上的「目標」不會知道那是底力效果。

因此建議：**主名用「零之X」，CHM 舊名保留為 `aliases` 供檢索**（與職業別稱同一套做法，見 `classAliases.js`）。
官方 Excel 的「底力技」維持不變。

### 4.3 角色身上的欄位

```js
zeroPower: {
  triggerId: 'love',
  effectId: 'scourge',
  choices: { damageType: '電', statuses: ['眩暈', '緩慢'] }, // 依 effect.needsChoice；值用專案既有中文列舉
  loveTargetPcId: 'pc_xxx',        // 僅 love
  clock: { max: 6, filled: 0 },    // combined 變體時 max = 4
  variant: null,                   // null | 'awakened' | 'combined'
  awakened: false,                 // awakened：建角只選效果，觸發於覺醒時才填
  combinedPairs: [],               // combined：每組 { partnerId, effectId, nickname }
}
```

要點：

- **命刻格數不是常數**：標準 6 格、合體之力 4 格 → `clock.max` 必須是資料，不要寫死。
- **「填充／清空」是共用操作**：零之目標、零之機運（零顆）都會動到「別人的命刻」，需要 `fillClock(pcId, n)` 這類跨角色操作。
- **零之機運需要「上一行」對照表**：`tierOrder = ['none','one','two','three']`，選擇時 `index - 1`，`none` 無上一行。
- **零之元素／零之天災要存玩家選擇**；零之元素存「兩種」，每次施展時再從中選一種。
- ~~**合體之力的效果存在「配對」上，不是存在角色上**：`combinedEffects: { 'pc_a|pc_b': 'scourge' }`，施展時檢查兩邊命刻皆滿。~~
  → 第一版實裝改成「每個角色各存自己的效果、只記 `combinedWith` 對方 id」，
  **2026-10-21 又改回配對層**：原文是「每個其他玩家角色各給一個效果」（四人團＝六個效果），
  單一欄位根本裝不下，遂改為 `combinedPairs: [{ partnerId, effectId, nickname }]`。
  「兩邊命刻皆滿」的檢查也已補上（`canUnleashZeroPower` 的 `partnerClockFull`，施展後回報 `partnerCleared` 由呼叫端清空對方命刻）。
