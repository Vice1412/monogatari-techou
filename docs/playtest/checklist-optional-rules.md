# 選用規則打勾表（魔晶石 ＋ 底力技 ＋ 營地活動）

> 自動生成自 `technospheres.js`／`zeroPowers.js`／`campActivities.js`（生成器：`scripts/gen-optional-rules-checklist.mjs`，已進版控）。
>
> **打勾規則**：`☐` 未測 → `✔` 測過無問題 → `▲` 有缺陷（填缺陷號）→ `✕` 不適用（附一句為什麼）。
>
> **這三樣與「職業」不同**：職業是「加內容」，這三樣是「**換條件**」——開啟後會拿走東西、改變必填欄位、鎖住職業數。
> 所以每一筆要回答的三問也不同：**①開啟後畫面有沒有告訴我它拿走了什麼 ②我在卡上真的做得到嗎 ③切回關閉後資料還在嗎**。
